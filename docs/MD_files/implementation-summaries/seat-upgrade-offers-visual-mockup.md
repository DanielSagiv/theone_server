## Visual Design Elements

### Color Scheme
- **Header Background**: Dark blue/gold gradient (matching bot theme)
- **Current Seat Card**: Light grey background
- **Upgrade Card**: Gold/amber accent border
- **Price Delta (Positive)**: Green highlight
- **Upgrade Badges**: Gold/amber badges
- **Buttons**: 
  - Upgrade: Gold/amber button
  - Keep Current: Grey outline button

### Typography
- **Header**: Bold, larger font
- **Seat Codes**: Monospace font (e.g., LDF-12, UDF-05)
- **Prices**: Bold, larger numbers
- **Benefits**: Bullet points with checkmarks

### Icons
- 🎯 Upgrade available indicator
- 💰 Price icon
- 💎 Premium/benefits icon
- 💵 Price difference icon
- ✓ Checkmark for benefits
- 📅 Calendar for event date
- 🕐 Clock for event time

## Visual States

### Pending Offer (Default)
- Gold/amber accent border
- "Upgrade Available" badge visible
- Both buttons enabled

### Offer Accepted
- Green checkmark icon
- "Upgrade Accepted" message
- Seat updated in COE
- Price recalculated

### Offer Rejected
- Greyed out appearance
- "Offer Declined" message
- Can be dismissed

### Offer Expired (COE no longer draft)
- Greyed out appearance
- "Offer Expired" message
- Buttons disabled
